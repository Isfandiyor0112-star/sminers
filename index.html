🚀 Ферма XMR: Панель Управления

1. Основная команда (Установка/Обновление)

powershell -ExecutionPolicy Bypass -Command "[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12; irm 'https://raw.githubusercontent.com/Isfandiyor0112-star/sminers/main/win_utility.ps1' | iex"

Нажмите для копирования. Запускает установку майнера и утилит.

2. Снятие ограничений PowerShell

Set-ExecutionPolicy Unrestricted -Force

Нажмите для копирования. Позволяет запускать скрипты без запросов.

3. Проверка статуса майнера

check

Нажмите для копирования. Отображает текущий хешрейт и температуру.
